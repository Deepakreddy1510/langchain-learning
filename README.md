# LangChain Learning

This repository contains my **daily learning and practice with LangChain and modern LLM application development**.

I am currently learning LangChain by following **Krish Naik's LangChain playlist**, and I use this repository to document what I learn by pushing my notebooks, experiments, and implementations as I progress.

The goal of this repository is not to present a finished application, but to **track my learning journey and build a strong practical understanding of LangChain and LLM-based systems**.

## What I'm Learning

* LangChain fundamentals
* Chat models and model integration
* Prompting and message handling
* Tools and tool calling
* Agents
* Retrieval-Augmented Generation (RAG)
* LangGraph
* LLM application development
* Working with different model providers
* Building and experimenting with AI/LLM workflows
